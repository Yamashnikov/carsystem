# 中古車販売管理システム（β版プロトタイプ）

会員ページ（顧客本人がログインする画面）を含む、Django製のβ版です。
ローカルマシンで動かして、業務フローの確認用に使うことを想定しています。

## セットアップ手順

```bash
# 1. 解凍したフォルダに移動
cd carsystem

# 2. 仮想環境を作成して有効化
python3 -m venv venv
source venv/bin/activate   # Windowsの場合: venv\Scripts\activate

# 3. Djangoをインストール
pip install django

# 4. データベース（SQLite）を作成
python3 manage.py migrate

# 5. 管理者アカウントを作成（対話式で質問されます）
python3 manage.py createsuperuser

# 6. サーバーを起動
python3 manage.py runserver
```

起動したら、ブラウザで以下にアクセスできます。

- **スタッフ用画面（推奨・こちらをスタッフに使ってもらう）**： http://127.0.0.1:8000/staff/
- 管理者用の詳細画面（Django Admin）： http://127.0.0.1:8000/admin/
- 会員ログイン画面： http://127.0.0.1:8000/member/login/

## 試し方（一連の流れ）

1. `/staff/` にアクセスすると、スタッフログイン画面が出ます。`createsuperuser`で作ったユーザー名・パスワードでログインしてください
2. ホーム画面の「＋ 新しいお客様を登録する」から、最低限の情報だけでお客様を登録します
3. 登録後の詳細画面で「会員ID・会員アカウントを発行する」ボタンを押すと、画面に会員IDと初回パスワードが表示されます（本番ではSMS送信に置き換える想定）
4. 表示された会員ID・パスワードで `/member/login/` からログイン
5. 初回はパスワード変更を求められます。変更後、マイページで
   「空欄の項目だけ入力できる」「一度入力すると編集できなくなる」動きを確認できます
6. 「顧客一覧」画面では、氏名・フリガナ・会員ID・電話番号で検索できます
7. `/staff/`のホーム画面にある「🔗 お客様自身に入力してもらう登録リンクを発行する」から、
   スタッフ自身が登録用URL（`/register/<トークン>/`）を発行できます。これがパターン②です
8. 車両・販売（取引）・買取・自社ローンなど、より詳しい業務データは `/admin/` から扱います

## スタッフ用アカウントと管理者アカウントを分ける

`/admin/`（管理画面）には触れさせたくないが、`/staff/`（スタッフ用画面）だけ使わせたいスタッフがいる場合は、以下の手順でアカウントを分けられます。

1. あなた自身の`superuser`アカウントで `/admin/` にログイン
2. 「認証と認可」→「ユーザー」→「ユーザーを追加」
3. ユーザー名・パスワードを設定して保存
4. 次の画面で表示される項目のうち、**「スタッフ権限」のチェックボックスは外したまま**保存する

これだけで、そのアカウントは `/staff/` にはログインできますが、`/admin/` には「権限がありません」と表示されて入れなくなります。動作確認済みです。

## 今の実装範囲

- 会員ページ・認証まわりを含む、社内業務の主要テーブル（全16テーブル）
- 車両・販売・買取・自社ローン・対応履歴などはDjango管理画面から操作
- デザイン（見た目）はまだ最小限です。業務フローの検証を優先しています
